# StreamSync Desktop App 🖥️

![StreamSync Logo](https://streamsync.apionlabs.org/logo.png)

**Share your screen. Connect face-to-face. Instantly.**

---

> **StreamSync** enables real-time screen sharing with two-way video chat — no accounts, no downloads, no friction. Just share a code and start collaborating.

🔗 **Launch Web App:** https://streamsync.apionlabs.org/app/

---

## ✨ Features

| Feature | Description |
|--------|------------|
| 🖥 Instant Screen Sharing | Share your entire screen, window, or tab with adaptive quality |
| 👥 Two-Way Video Chat | Real-time camera & microphone sync |
| 🔐 Peer-to-Peer Privacy | Direct device connection, no media stored |
| 🔗 Simple Room Codes | 6-character codes, no accounts required |
| ⚡ Low Latency | Optimized WebRTC with fallback |
| 🎨 Clean UI | Minimal, distraction-free dark interface |

---

## 🔄 How StreamSync Works

### 1️⃣ Host starts session
- Click **Host**
- Share your screen
- Allow camera & microphone
- Get a unique room code

### 2️⃣ Share the code
- Copy the code or link
- Send it via any platform

### 3️⃣ Guest joins
- Enter the code or open the link
- Allow permissions
- Connected instantly 🎉
